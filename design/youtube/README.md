# Nerve YouTube banner

`nerve-youtube-banner.html` is the editable 2560 × 1440 source for
`public/brand/nerve-youtube-banner.png`. It uses the Arena palette and the
same Barlow Condensed / IBM Plex Mono Latin font files used by the existing
brand assets.

Render with Chrome at device scale factor 1 and a 2560 × 1440 viewport. Keep
the name, tagline, URL, and meter within the centered 1544 × 423 text-safe area;
the rest of the canvas supplies the TV background. YouTube's banner guidance is
at <https://support.google.com/youtube/answer/10456525>.
