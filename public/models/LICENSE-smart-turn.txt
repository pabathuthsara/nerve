smart-turn-v3.2-cpu.onnx

Smart Turn v3.2, the int8-quantised CPU export, by Daily (pipecat-ai).
Downloaded unmodified from
  https://huggingface.co/pipecat-ai/smart-turn-v3/resolve/main/smart-turn-v3.2-cpu.onnx
Source, training code and data: https://github.com/pipecat-ai/smart-turn
8,679,182 bytes, SHA-256
  2bb026316b14a660486a75b1733cd3fbab8c2fd0314dc9af7be49f8cca967e4f
which is the LFS object id Hugging Face lists for that file (checked
24 September 2026). If `shasum -a 256` disagrees, the file is not upstream's.

Served to the browser as a static file and run there by
lib/voice/elevenlabs/smart-turn/ (onnxruntime-web). It reads the user's own
microphone audio on the user's device; nothing it hears is sent anywhere by it.
